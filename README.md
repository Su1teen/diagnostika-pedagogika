# 📖 Ерекше білім беру қажеттіліктері бар балалардың психологиялық-педагогикалық диагностикасы — Электрондық оқулық

Заманауи, жоғары деңгейдегі академиялық веб-оқулық. C# / WPF / .NET 8 десктоп бағдарламасынан толық вебке көшірілген және жетілдірілген.

## ✨ Мүмкіндіктері
- **Толық құрылымдалған оқулық**: 
  - Кіріспе, 1-тарау (1, 1.2, 1.3, 1.4, 1.5 бөлімдері), 2-тарау (2, 2.1, 2.2, 2.3 бөлімдері), 3-тарау (Практикалық тапсырмалар мен диагностикалық әдістемелер), Қорытынды, Әдебиеттер тізімі.
  - 1600-ден астам абзац, кестелер, диаграммалар және **15 түпнұсқа сурет пен схема** сақталған.
- 📊 **Тұрақты бөлім 1: Бағалау және рефлексия (Assessment & Reflection)**:
  - Оқулықтағы барлық 244 өзін-өзі бағалау, критерийлер, дескрипторлар, тесттер мен диагностикалық сұрақтар бойынша сүзу жүйесі.
  - Кілт сөздер бойынша сүзу pills (бағалау, критерий, дескриптор, рефлексия, тест, т.б.).
  - «Оқулықтағы осы бөлімге өту →» батырмасымен нақты абзацқа секіру және оны жарықтандырып көрсету (highlight animation).
- 💡 **Тұрақты бөлім 2: Әдістемелік нұсқау (Methodical Guidelines)**:
  - Барлық 108 әдістемелік нұсқаулықтар, практикалық алгоритмдер, кезеңдер мен ұсынымдар каталогы.
  - Мұғалімдер мен логопед мамандарға арналған кеңестер.
- 👤 **Модальді терезелер**:
  - «Алғы сөз» (толық мәтінді ресми кіріспе).
  - «Автор туралы» (Есенғұлова М.Н., фотосы, ғылыми дәрежелері, гранттық жобалары).
- 🔍 **Толықмәтінді іздеу (Ctrl+K)**: Бүкіл оқулық бойынша сөздер мен терминдерді жылдам табу.
- 🎨 **Академиялық оқу дизайны**:
  - Ақ қағаз, Сепия және Қараңғы түнгі режим.
  - Қаріп өлшемін реттеу (A- / A+).
  - Оқу барысының индикаторы.
  - Басып шығару (Print) мүмкіндігі.

## 🚀 Жергілікті іске қосу (Local Development)

```bash
# 1. Тәуелділіктерді орнату
npm install

# 2. Әзірлеу серверін қосу
npm run dev
```

Браузерде ашыңыз: `http://localhost:5175`

---

## 📦 Өндірістік нұсқаны жинау (Production Build)

```bash
npm run build
npm start
```
`http://localhost:3000` мекенжайында өндірістік нұсқа іске қосылады.

---

## ⚡ Тез іске қосу (Windows)
Жоба қалтасындағы `start.bat` файлын екі рет басыңыз. Сервер автоматты түрде қосылып, браузер ашылады.

## 🚆 Railway-ге деплой жасау (Deploy to Railway)

1. Осы қалтаны GitHub репозиторийіңізге жіберіңіз:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/Su1teen/diagnostika-pedagogika.git
   git push -u origin main
   ```
2. [railway.app](https://railway.app) сайтында **New Project → Deploy from GitHub repo** таңдаңыз.
3. `diagnostika-pedagogika` репозиторийін таңдаңыз. Railway жобаны автоматты түрде анықтап, `npm start` арқылы `server.js` файлын бірден іске қосады!
